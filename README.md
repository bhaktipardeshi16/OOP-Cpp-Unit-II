Programs Included
Program 01 - Smart Agriculture Sensor Monitor
This program manages soil sensor readings using a SoilSensor class. It stores sensor ID, moisture level, and timestamp and allows sensor readings to be updated.

Program 02 - Student Attendance Management System
This program records student attendance and calculates the attendance percentage based on the number of present and total days.

Program 03 - E-Commerce Product Catalog
This program manages product information such as product ID, name, price, and stock quantity. It also demonstrates static members, inline functions, constructors, and destructors.

Program 04 - Employee Payroll System
This program manages different types of employees, including full-time employees, part-time employees, and interns. It calculates their salaries using inheritance and polymorphism.

Program 05 - Digital Payment Gateway
This program processes different types of payments, including credit card, UPI, and net banking. It demonstrates inheritance, abstract classes, and runtime polymorphism.

Program 06 - Vehicle Fleet Management
This program manages different vehicles such as trucks, delivery vans, and bikes. It demonstrates inheritance and runtime polymorphism using a common Vehicle class.

Program 07 - CAD Shape Drawing System
This program represents circles, rectangles, and triangles. It uses abstract classes and polymorphism to draw shapes and calculate their areas.

Program 08 - Complex Number Calculator
This program performs addition, subtraction, and multiplication of complex numbers. It demonstrates operator overloading for performing operations on complex number objects.

Program 09 - Input Validation Service
This program validates different types of inputs such as marks, amounts, and names. It demonstrates function overloading for different data types.

Program 10 - Student Record File System
This program stores student records in a CSV file and reads them back for displaying student information. It demonstrates file input and output operations.

Program 11 - Server Log Analyzer
This program reads a server log file and identifies ERROR and CRITICAL events. It demonstrates file handling, string searching, structures, and vectors.

Program 12 - Binary File for Fixed-Size Records
This program stores and retrieves image metadata such as width, height, and format using a binary file. It demonstrates binary file handling and structures.

Program 13 - Secure Banking Transaction Module
This program performs banking operations such as deposit and withdrawal. It uses exception handling and a custom exception to handle insufficient account balance.

Program 14 - Generic Sorting Service
This program sorts integers, floating-point numbers, and strings using a generic sorting function. It demonstrates function templates and generic programming.

Program 15 - Template-Based Stack
This program implements a stack that can store different data types. It demonstrates class templates, dynamic memory allocation, and exception handling for stack overflow and underflow.

Program 16 - Employee Directory and Salary Lookup
This program manages employee details using STL vector and map. It sorts employees by age, searches for an employee's salary, and finds the highest-paid employee.

Program 17 - Web Server Log Analysis
This program analyzes server logs and counts the number of requests made by each IP address. It uses STL containers, pairs, sorting, and lambda functions.

Program 18 - Student Grade Analytics
This program analyzes student marks to calculate average, minimum, maximum, top three marks, unique marks, and grade distribution using STL containers and algorithms.
